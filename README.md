# Claude Console Clone - Facturación

Clon visual de la página de Facturación de Claude Console.
Stack: Next.js 14 (App Router) + TypeScript + Tailwind CSS.

## Desarrollo
npm install
npm run dev

## Deploy en Vercel
1. Sube el repo a GitHub.
2. Importa el repo en https://vercel.com/new
3. Deploy automático.
